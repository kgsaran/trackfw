KG owns the trackfw project (a Go CLI for AI-native delivery governance). Reviews are expected to
be direct: "approve / approve with caveats / block", each finding tied to file+line evidence.

KG explicitly dislikes style-preference lists — wants findings that "will cost dearly later", not
formatting opinions. If the verdict is "all good", say so — that is a valid answer.

**How to apply:** lead with veredito, keep findings ordered by severity, separate "fix now" from
"file as issue". Never report a finding without command + output as evidence.
