## 🔴 Armadilhas de instrumento medidas nesta campanha (14)

As que mais custaram, e que valem para amanhã:

| armadilha | sintoma |
|---|---|
| `pgrep -f "make quality"` | **casa a si mesmo** — o laço de espera contém a string. Custou 5 h reportando "ainda rodando". Use `ps -eo comm \| grep -cx make` |
| marcador de fim (`exit=`/`RC=`) | o `make` termina mas o `echo` nunca roda. **1468 linhas no log = run completo**. Travou 3 subagentes hoje |
| barreira concorrente | rodar build/sonda junto **aborta** a suíte; o log termina **limpo**, sem `make: *** Error`, e **parece sucesso** (188 de 630) |
| `head` truncando evidência | reportei "silencioso" o que não era. Redirecione `stdout`/`stderr` para **arquivos separados** |
| `^FAIL` como métrica | **cega**: deu 0 numa barreira abortada. `^FAIL\|FALHA` é **pior que inútil** (4 na que falhou, 6 na que passou). Só **`": FALHA"`** discrimina |
| gates com `git ls-files` | não veem arquivo **untracked** — a barreira do ML-1A varreu 142 arquivos e **não viu** o pacote que o ML-1A criou. `git add -N` antes |
| `grep` do shell | é **`ugrep` com `--ignore-files`**. Para contagem que vira afirmação, use `/usr/bin/grep` |
