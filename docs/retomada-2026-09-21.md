As que mais custaram, e que valem para amanhã:

| armadilha | sintoma |
|---|---|
| `pgrep -f "make quality"` | **casa a si mesmo** — o laço de espera contém a string. Custou 5 h reportando "ainda rodando". Use `ps -eo comm \| grep -cx make` |
| marcador de fim (`exit=`/`RC=`) | o `make` termina mas o `echo` nunca roda. **1468 linhas no log = run completo**. Travou 3 subagentes hoje |
